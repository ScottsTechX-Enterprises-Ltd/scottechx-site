## 💻 What We Do

**Product Development** — School management platforms, REST APIs, and mobile clients built with Node.js, Express, NestJS, Prisma, and PostgreSQL.

**Developer Tooling** — 17+ open-source command-line tools for networking, data handling, build, and deployment workflows.

**Community Empowerment** — Free tools, open documentation, and automation scripts for developers worldwide.

### Install the Developer Tool Suite

Each tool lives in its own repository. Clone what you need and run it straight from source:

```bash
git clone https://github.com/ScottsTechX-Enterprises-Ltd/ScottsTechX-jq.git
git clone https://github.com/ScottsTechX-Enterprises-Ltd/ScottsTechX-docker.git
git clone https://github.com/ScottsTechX-Enterprises-Ltd/ScottsTechX-terraform.git
```
